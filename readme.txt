A simple responsive banner slider plugin for WordPress and Bricks Builder.

== Description ==

Easily create a responsive banner slider with image, title, link, and auto-play features. Works seamlessly with Bricks Builder.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/banner-slider` directory.
2. Activate the plugin through the ‘Plugins’ screen in WordPress.
3. Use the `[banner_slider]` shortcode or drag the element in Bricks Builder.
